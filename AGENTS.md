# AI Usage Record

AI assistance was used to draft the project structure, Java classes, tests, and decision notes for this shopping basket assignment. The generated code was reviewed against the assignment requirements, adjusted for validation and BigDecimal money handling, and prepared for verification with Maven tests.

AI assistance was also used to add the collections and stream pipelines order-summary deliverable. The order model, customer key, immutable summary result, stream-based filtering, sorting, totals, grouped customer revenue, runnable example, tests, and decision notes were reviewed against the deliverable requirements.

The base environment did not include `java`, `javac`, or `mvn`, so portable OpenJDK 17 and Maven archives were installed under `/tmp/codex-java-tools` for local verification. The project was then tested with `mvn test`, and the runnable demo was checked with `mvn exec:java`.
